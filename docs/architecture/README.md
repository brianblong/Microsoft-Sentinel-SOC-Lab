# Architecture

Store current-state and target-state diagrams, data flows, trust boundaries, network layouts, identity relationships, and component inventories here.

Each diagram should include:

- Version or date
- Scope and assumptions
- Trust boundaries
- Telemetry paths
- Management paths
- Internet exposure
- Secrets or identity dependencies
- Expected cost-bearing services

Prefer editable source formats such as Mermaid or diagrams-as-code alongside exported images.
